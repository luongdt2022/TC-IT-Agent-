⚡ Phần 3: Bộ Ba "Động Cơ Tăng Áp" (speckit-autopilot × speckit-uiux × speckit-delta)

Cách thức 3 kỹ năng cốt lõi này giải quyết bài toán tốc độ, chất lượng giao diện và sự an toàn khi có thay đổi nghiệp vụ:

🚀 1. speckit-autopilot (Trục Cao Tốc)

Giải quyết: "Gọi 1 lần — Hoàn thành cả Epic".

  • Tự động chạy chuỗi: specify $\rightarrow$ plan $\rightarrow$ uiux $\rightarrow$ tasks $\rightarrow$ implement $\rightarrow$ converge.
  • Tự động chuyển giao giữa TechLead $\rightarrow$ Dev $\rightarrow$ QC mà không cần gõ lệnh thủ công.
  • Chỉ dừng lại xin ý kiến PO tại 3 Checkpoint: (1) Mơ hồ spec, (2) Quyết định kiến trúc lớn, (3) Nghiệm thu.

🎨 2. speckit-uiux (Cầu Nối Giao Diện)

Giải quyết: Đưa đúng 100% Wireframe vào code.

  • Đọc tệp wireframe_*.html từ Basic Design $\rightarrow$ Ánh xạ sang React 19 / TypeScript.
  • Bắt buộc bọc qua component <Async> chuẩn hóa đủ 5 UX States: Empty, Loading, Error, Success, Partial.
  • Tự động kích hoạt Playwright chụp ảnh màn hình Desktop & Mobile lưu vào thư mục E2E để duyệt bằng mắt.

🛡️ 3. speckit-delta (Thay Đổi Phi Phá Hủy)

Giải quyết: Sửa yêu cầu mà không vỡ code cũ.

  • Lập ma trận phân tích tác động 8 bề mặt (Cross-Surface Impact Matrix).
  • Cập nhật spec & plan theo nguyên tắc Append-only (không xóa lịch sử).
  • Sinh EF Core Migration mới an toàn (cột mới luôn Nullable/Default, không mất dữ liệu).
  • Chạy kiểm thử hồi quy bảo đảm 100% code cũ tiếp tục chạy tốt.

📖 Phần 5: Kỷ Luật Bảo Vệ Nguồn Xác Thực Sống (Living SSOT) & Quản Lý Task 2 Tầng

1. Trục Đồng Bộ Quản Lý Task 2 Tầng (Bidirectional Sync)

Đảm bảo tính nhất quán tuyệt đối giữa quản trị vĩ mô của PO và thực thi vi mô của Dev:

[TẦNG 1: PO & BA]
Specification/02_BASIC_DESIGN/DANH_SACH_TIEN_DO_BASIC_DESIGN.md
       ↕ (Cầu nối tự động: /nacen-srs-to-speckit)
[TẦNG 2: DEV & QC]
SourceCode/specs/ROADMAP.md (Quản lý tiến độ vi mô của từng Epic)
       ↕ (Phân rã chi tiết)
SourceCode/specs/00X-/tasks.md (Checkbox [x] kèm lệnh test kiểm chứng)
  • Top-Down: PO đổi phạm vi trên bảng Basic Design $\rightarrow$ Tự động cập nhật vào spec.md.
  • Bottom-Up: Dev/QC tích [x] trong tasks.md $\rightarrow$ Tự động cập nhật % hoàn thành lên Roadmap.

2. Nguyên Tắc Nguồn Xác Thực Duy Nhất Sống (Living SSOT)

Triệt tiêu vĩnh viễn tình trạng lệch pha giữa Word, Excel và Code:

Quy tắc sắt đá: Trong quá trình phát triển, từng tệp SourceCode/specs/00X-.../spec.md là nguồn chân lý duy nhất (Living SSOT). Mọi quy tắc BR-*, cấu trúc DB-*, điểm cuối API-* sinh ra trong thực tế đều cập nhật vào đây.

Tuyệt đối không sửa tay vào file Word Master SRS: File Word chỉ là bản xuất bản (Compiled Artifact). Khi cần bàn giao đối tác, PO chạy /nacen-aggregate-srs để tự động quét toàn bộ spec.md sống và biên dịch ra file Word chuẩn mực.
