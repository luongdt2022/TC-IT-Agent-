👥 2. Đội Ngũ 6 Agent Chuyên Trách Toàn Vòng Đời Dự Án

Phân định rạch ròi giữa Giai đoạn tiền dự án (Pre-sales) và Giai đoạn thực thi (5 Stage-Gates) theo nguyên tắc Phân lập trách nhiệm (Separation of Concerns) và Maker – Checker.

PS Agent Presale & Solution

Chuyên gia tư vấn kỹ thuật cao cấp & tài chính dự án. Cầu nối giữa khách hàng/C-Level và đội ngũ kỹ thuật.

  • Thẩm định đề bài thầu (RFP / RFI) & tính khả thi.
  • Đề xuất giải pháp kiến trúc tối ưu (So sánh Trade-off).
  • Bóc tách Man-Month (MM), dự toán chi phí Cloud & TCO.
  • Lập hồ sơ kỹ thuật chuyên nghiệp (IT Technical Proposal).
PO/PM Agent Gate 1 & Gate 5

Product Owner kiêm Project Manager. Người giữ chìa khóa phạm vi, giá trị sản phẩm và nghiệm thu xuất xưởng.

  • Sàng lọc yêu cầu (Scope Triage), xác định MVP / Post-MVP.
  • Quản lý Master Roadmap, Milestones & Story Mapping.
  • Điều phối các cuộc họp đa tác tử (Party Mode).
  • Gác cổng Gate 1 (duyệt đề bài) & Gate 5 (nghiệm thu DoD).
BA Agent Gate 1 Specialist

Senior Business Analyst. Chuyên sâu khơi gợi yêu cầu tiềm ẩn và chuẩn hóa tài liệu thiết kế cơ sở.

  • 9 kỹ thuật khơi gợi nghiệp vụ (5 Whys, Laddering...).
  • Xây dựng Thiết kế Cơ sở (Basic Design - Kihon Sekkei).
  • Đặc tả yêu cầu phần mềm SRS 7 mục (mã hóa REQ-*, BR-*).
  • Kiểm soát ma trận truy vết khép kín (Traceability).
TL/SA Agent Gate 2 & Gate 3

Software Architect & Tech Lead. Người gác cổng kiến trúc sạch và chất lượng kỹ thuật mã nguồn.

  • Thiết kế kỹ thuật chi tiết (Detail Design: ERD, API, Sequence).
  • Lập kế hoạch phân rã module kiến trúc (plan.md).
  • Bảo vệ ranh giới Clean Architecture (Chống rò rỉ dữ liệu).
  • Rà soát code đối kháng (Adversarial Code Review).
Dev Agent Execution Specialist

Senior Full-Stack Developer. Thực thi chính xác 1:1 theo tasks.md, không đoán mò, không sinh code thừa.

  • Phân rã checklist công việc chi tiết [BE]/[FE].
  • Lập trình tuần tự bám sát task có kiểm chứng [x].
  • Chuẩn hóa giao diện 5 trạng thái UX qua component <Async>.
  • Viết Unit Test cho 100% Business Rules (TDD).
EC Agent Gate 4 Guard

Edge-Case Hunter & QC Specialist. "Thợ săn lỗi góc khuất" đóng vai trò đối kháng để bảo vệ chất lượng.

  • Săn kịch bản ngoại lệ, lỗi biên logic, spam click.
  • Fuzzing ma trận phân quyền RBAC & lỗ hổng leo thang quyền.
  • Tự động sinh kịch bản Playwright E2E từ Acceptance Criteria.
  • Gác cổng Quality Gate 4 (Unit + DB Integration + E2E).

📁 4. Khung Kiến Trúc Quản Lý Thư Mục & Cơ Chế Chống Rác

Mỗi tệp tin sinh ra hoặc cập nhật đều có một địa chỉ cố định duy nhất. Áp dụng kỷ luật Zero-Tolerance Root Dumping: Cấm tuyệt đối xả file bừa bãi ra thư mục gốc.

{{PROJECT_ROOT}}/ ├── .agents/ # 6 Persona chuẩn (ps, po-pm, ba, techlead-sa, dev, ec) ├── AGENTS.md # Quy chế điều phối đa nền tảng tối cao ├── constitution.md # Hiến pháp kỹ thuật & Ranh giới chất lượng │ ├── docs/ # TOÀN BỘ TÀI LIỆU DỰ ÁN (Có địa chỉ cố định) │ ├── 00-presale-proposal/ # [PS] PROPOSAL.md, ESTIMATION_AND_COST.md, SOLUTION_COMPARISON.md │ ├── 01-basic-design/ # [BA] BD-00-overview.md, BD-01-c4-context.md, BD-02-domain.md │ ├── 02-detail-design/ # [SA] DD-01-database-erd.md, DD-02-api-contracts.md, DD-03-sequence.md │ ├── decisions/ # [SA] Architecture Decision Records (ADR-001, ADR-002...) │ └── change-requests/ # [PO/BA] Quản lý yêu cầu thay đổi (CR-001, CR-002...) │ ├── backlog/ # [PO] ROADMAP.md, EPICS/, USER_STORIES/ ├── specs/ # [TEAM] ĐẶC TẢ TÍNH NĂNG THEO SPEC KIT │ └── [epic-id]/ # Ví dụ: specs/EPIC-01-AUTH/ (spec.md, plan.md, tasks.md, checklist.md) │ ├── src/ # [DEV] MÃ NGUỒN CHUẨN CLEAN ARCHITECTURE │ ├── Domain/ # Entities, Value Objects, Domain Events (Không phụ thuộc gì) │ ├── Application/ # Use Cases, DTOs, Business Rules Validators, Interfaces │ ├── Infrastructure/ # DB Context, Repositories, Third-party SDKs, Cache, Queue │ ├── Presentation/ (API/) # Controllers, Middlewares, Scoped RBAC Filters │ └── WebApp/ (Client/) # Frontend React/Vue chuẩn 5 trạng thái UX qua <Async> │ └── tests/ # [EC/DEV] HỆ THỐNG KIỂM THỬ 3 TẦNG ├── unit/ # Unit test Business Rules (Coverage 100% BR-*) ├── integration/ # Database Integration test & API Endpoints test └── e2e/ # Playwright End-to-End Visual QA

Cơ chế kiểm soát 3 tầng chống xả rác (3-Tier Anti-Clutter):

Tầng 1 (Luật Root): Chỉ cho phép các file config chuẩn ở root. Cấm file rác .md hay script tạm.
Tầng 2 (Hợp đồng I/O của Skill): Từng file SKILL.md quy định cứng thuộc tính Target Output File. Agent chỉ được ghi file vào đúng path quy định.
Tầng 3 (Gác cổng sa-guard): Quét kiểm tra cấu trúc định kỳ, tự động dọn dẹp file lạc vị trí và chặn Quality Gate nếu còn rác.

🔄 5. Các Quy Trình Chuẩn (Standard Workflows: wf-*)

Con người kích hoạt bằng lệnh hoặc ngôn ngữ tự nhiên. Bên trong từng workflow là kịch bản điều phối liên tác tử (Multi-Agent Choreography) chuyển giao đúng người, đúng việc.

Lệnh Workflow Agent Chủ Trì Luồng Phối Hợp Bên Trong Mục Đích & Giá Trị
wf-presale PS Agent PS (Đề bài) ➔ SA (Kiến trúc đề xuất) ➔ PS (Proposal & Báo giá) Chuyển đề bài thô / RFP thành Hồ sơ giải pháp IT hoàn chỉnh và bảng tính Man-Month.
wf-kickoff PO/PM Agent PO (Nhận bàn giao) ➔ BA (Elicitation & Basic Design) ➔ SA (C4) ➔ PO (Roadmap) Khởi động dự án mới, thiết lập khung xương sống kiến trúc (Walking Skeleton).
wf-refactor SA Agent SA (Quét mã nguồn cũ) ➔ SA (Kiến trúc đích) ➔ PS (Dự toán chi phí) ➔ PO (Lộ trình) Quét dự án cũ (Chỉ đọc), phát hiện nợ kỹ thuật và lập đề xuất Refactor an toàn 100%.
wf-autopilot PO/PM Agent BA (Spec) ➔ SA (Plan) ➔ Dev (Tasks & Code) ➔ EC (Hunt & Test) ➔ PO (Gate 5) Phát triển tự động toàn trình 1 Epic/Tính năng từ Spec đến Code hoàn thiện.
wf-hotfix EC + Dev Agent EC (Tái hiện lỗi Red Test) ➔ SA/Dev (Sửa mã tối thiểu) ➔ EC (Regression Pass) ➔ PO (Post-Mortem) Vá lỗi khẩn cấp Production/UAT theo chuẩn phẫu thuật tối thiểu (Surgical Fix) và Zero Regression.
wf-delta SA + BA PO (Duyệt CR) ➔ SA/BA (Sửa Design trước) ➔ Dev (Sửa Code sau) ➔ EC (Test) Xử lý yêu cầu thay đổi (Change Request) đảm bảo tài liệu và code luôn đồng bộ 100%.
wf-uiux Dev Agent Dev (Dựng 5 UX States với <Async>) ➔ EC (Chụp ảnh Playwright Visual QA) Chuẩn hóa giao diện frontend mượt mà: Loading, Empty, Error, Success, Updating.
wf-audit SA Agent SA (Clean Arch) ➔ BA (Traceability REQ-BR-DB) ➔ EC (Test Coverage) Kiểm toán toàn diện định kỳ trước khi phát hành (Release Gatekeeper).
